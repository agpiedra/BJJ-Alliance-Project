## Before you answer (as sent)

- **"Eligible" means ready for instructor review. It is never an automatic award.** When a student
  reaches the number of classes (or the time) for a stripe, degree or belt, the software shows
  that the student is eligible, and an instructor decides whether to award it. Question 9 asks
  separately whether any academy should ever be able to switch on automatic awards.
- **The examples use invented names and round numbers.** Where an example says "30 classes per
  stripe", that is only an illustration for the adult belts. The real numbers you use are not
  changed by this form.
- **Adults and kids can have different rules.** Questions 1 to 5, 8, 10, 11 and 12 have two
  answer lines, one for adults and one for kids. If both should follow the same rule, mark both
  lines the same. Question 6 (black belt) concerns adults only, question 7 concerns kids only,
  and question 9 (automatic awards) is one answer for the academy as a whole.
- **Black belt works by time, not by classes.** Question 6 is separate for that reason. None of
  the class-count examples in the other questions describe how the black belt works.
- **How to answer:** put an `x` in exactly one box per answer line, for example `[x]`. Every box
  starts empty. If you are not sure, tick "Not decided yet", and write what you would need to know
  in the comments. A blank line is treated as "not decided yet", never as a preference.

system had **30 recorded qualifying classes** for Ana. **One additional class** (the 8:55 pm

  again, it shows 1 of 30.

In every option the late class appears on a list, and it never disappears silently.

apply for that group; a late class then works the same way as the waiting classes.
