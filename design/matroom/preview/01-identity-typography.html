Mark and wordmark

The mark is the geometry of the landing reference’s CSS mark (two 2 px rules in a 24 px box, skewed −12°), redrawn as SVG so it scales cleanly. The reference has no logo file, so this is a faithful reproduction, not a new logo. The app tile is the same mark in --brand on --on-brand. The wordmark is text: IBM Plex Sans SemiBold, uppercase, −0.02em (the reference used Segoe UI at weight 750, which the app does not ship).

Typography

Two registers, as approved: an editorial serif for Persuade surfaces and a quiet sans for Operate surfaces. The serif here is the Georgia stack from the reference, which renders as Georgia on Windows/macOS/iOS and as a different serif elsewhere; vendoring an open serif is decision D2 and would be specimen-tested first. The copy shown is the app’s current landing text, not approved landing copy (D7).
